0x01 // Technical Specification & Remediation Patch

### Summary & Root-Cause Static Analysis

1. **Out-of-Bounds Stack Read via Non-Null-Terminated `strncpy` into Uninitialized Stack Array in `emit_property()` (`internal/cbm/iris_export_xml.c:217-256`, `CWE-170` / `CWE-125`):**
   `PropParam params[MAX_PARAMS]` is declared on the stack without zero-initialization, and `strncpy(params[np].param_value, db, MAX_NAME - 1)` copies up to `255` bytes without writing a null terminator at index `MAX_NAME - 1` (`255`). When a `<Parameter><Default>` element in an indexed InterSystems IRIS `.xml` file is `>= 255` bytes long, `ub_app(b, params[i].param_value)` calls `strlen()` on an unterminated stack buffer, reading past `params[i].param_value` across uninitialized stack memory.

2. **Unchecked Pointer Subtraction in `extract_attr()` (`internal/cbm/iris_export_xml.c:54-75`, `CWE-125`):**
   `for (const char *p = ts; p < te - an; p++)` subtracts `an = strlen(attr)` from `te` without verifying `(size_t)(te - ts) >= an`, and advances `p += an + 1` without checking `vs <= te` prior to `char q = *p`.
