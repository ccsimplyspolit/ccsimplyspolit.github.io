Predictable /tmp Symlink Clobbering in Install & Hook Scripts (akitaonrails/ai-memory)

PUBLISHED GHSA: GHSA-jr85-7366-xrm2 HIGH (8.2) CWE-59 CWE-377 Published: 2026-11-04

0x01 // Advisory Summary

ai-memory (< 3.3.2) used predictable, fixed temporary file paths in /tmp across installation and runtime hook scripts without O_NOFOLLOW or mktemp isolation, enabling local symlink arbitrary file overwrite and denial of service.

0x02 // Affected Versions & Remediation

  • Repository: akitaonrails/ai-memory
  • Affected Versions: < 3.3.2
  • Patched Versions: 3.3.2
  • CVSS v3.1 Vector: CVSS:3.1/AV:L/AC:L/PR:N/UI:R/S:C/C:N/I:H/A:H
