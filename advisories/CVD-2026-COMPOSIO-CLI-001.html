CVD-2026-COMPOSIO-CLI-001: Fail-Open Consumer Permission Gate on Config Fetch Error / Expired Cache & Case-Sensitive Override Bypass in @composio/cli (tool-permissions.ts)

Target Repository: ComposioHQ/composio (commit d8f8204806, 2026-10-24T01:03:07Z)
Affected Component: ts/packages/cli/src/services/tool-permissions.ts (lines 401-567) & ts/packages/cli/src/commands/proxy.cmd.ts (lines 315, 521-527)
Researcher: Serhii Shunko (@sshunko / @ccsimplyspolit, ORCID 0009-0002-4183-0361)

1. Summary

During a defensive static source audit of `https://github.com/ComposioHQ/composio` (`main` branch, commit `d8f8204806` / `1239853a93`, pushed `2026-10-24T01:03:07Z`), I identified three security defects in the consumer permission gate introduced/updated in commit `1239853a93` (*'fix(cli): enforce the consumer permission gate on composio proxy (#5093)'*): 1. **Fail-Open Permission Gate on `fetchConsumerConfig` Failure & Expired Cache Fallback (`CWE-636`, `tool-permissions.ts:463-496, 561-567`)**: When `refreshConsumerPermissionSnapshot()` fails to fetch `ORG_CONSUMER_CONFIG_PATH` (`/api/v3.1/org/consumer/config`), its `Effect.catchTag('services/ToolPermissionsRequestError')` handler (`lines 463-469`) returns `undefined` instead of failing closed to `ask_every_call`. Then `getConsumerPermissionSnapshot()` (`line 496`) executes `return refreshed ?? cached;`, returning an expired `cached` snapshot (even when `Date.now() - cached.fetchedAt > PERMISSION_SNAPSHOT_CACHE_TTL_MS` and the organization has since enabled `enhanced_controls` or `always_deny`), or `undefined` when no cache exists — which `resolveGateState()` (`line 564`: `if (params.snapshot === undefined) return 'skip';`) treats as `'skip'` (allowing execution without prompting). 2. **Empty `connectedAccountIds` Bypasses `enhancedControlsEnabled` (`CWE-285`, `tool-permissions.ts:404-435, 565`)**: When `enhancedControlsEnabled === true` and `connectedAccountIds.length === 0`, lines 404-435 skip `CONSUMER_PERMISSIONS_RESOLVE_PATH` and set `permissions: undefined`, causing `resolveGateState()` (`line 565`: `if (!params.snapshot.enhancedControlsEnabled || !params.snapshot.permissions) return 'skip';`) to return `'skip'`. 3. **Case-Sensitive Override Key Lookup (`CWE-178`, `tool-permissions.ts:499-502, 548-556` & `proxy.cmd.ts:315, 521`)**: `proxy.cmd.ts` lowercases `normalizedToolkit = toolkit.toLowerCase()`, whereas `resolvePermissionState()` looks up `permissions?.overrides?.[permissionField(params.toolSlug, params.connectedAccountId)]` case-sensitively without normalizing override keys.

- **BEFORE PATCH**: When `refreshConsumerPermissionSnapshot()` fails (`refresh_ok=False`), `getConsumerPermissionSnapshot()` falls back to the expired `allow_all` cache or `undefined` (`'skip'`), and case-mismatched override keys (`'GMAIL:con_1': 'always_deny'` vs `'gmail:con_1'`) evaluate to `'allow_all'`.
- **AFTER PATCH**: Fails closed to `'ask_every_call'` on refresh failure, never returns expired cache entries, and normalizes override keys to lowercase.

5. Security Impact

On consumer projects with `enhanced_controls` enabled, transient failure or blocking of `/api/v3.1/org/consumer/config`, an expired local cache entry, or uppercase toolkit override keys (`GMAIL:<account>`) allows `composio proxy` and `composio execute` calls to bypass `always_deny` and `ask_every_call` policies.
