CVD-2026-TWILIO-MCP-001: Unencoded Path Parameter Interpolation and ToolFilters (--services / --tags) Authorization Bypass in twilio-labs/mcp

Researcher: Serhii Shunko (@ccsimplyspolit)

Repository: twilio-labs/mcp

HackerOne Program: twilio (Scope ID 1047303 — github.com/twilio-labs (twilio-labs/mcp))

Affected Component: packages/openapi-mcp-server/src/utils/http.ts (lines 111-139), packages/openapi-mcp-server/src/server.ts (lines 93-115), packages/mcp/src/tools/uploadFunction.ts (lines 16-17), packages/mcp/src/tools/uploadAsset.ts (lines 17-18)

Weakness / Severity: CWE-22 / CWE-285 · High (CVSS 8.1)

Summary

I identified a URL path traversal and tool-filter bypass vulnerability in `twilio-labs/mcp` (`@twilio-alpha/mcp` and `@twilio-alpha/openapi-mcp-server`). In `packages/openapi-mcp-server/src/utils/http.ts` (lines 111-139), `interpolateUrl()` substitutes caller-supplied string parameters directly into `{param}` URL templates without `encodeURIComponent()` or path-segment validation, and `uploadFunctionExecution` / `uploadAssetExecution` interpolate `serviceSid`, `functionSid`, and `assetSid` without SID validation.

Impact

When an operator restricts the Twilio MCP server using `--services` or `--tags` (for example, exposing only a single message tool), a prompt-injected LLM can traverse to arbitrary Twilio REST API endpoints (such as creating new API keys at `/Keys.json` or initiating calls at `/Calls.json`) using the server's configured Twilio API Key and Secret.
