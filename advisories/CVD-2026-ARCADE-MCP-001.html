CVD-2026-ARCADE-MCP-001: Path Traversal in _requirement_specs (-r Includes), Unblocked Loader Env Vars in deploy_config.py, and Raw Output Value Leak in ToolExecutor._serialize_output

High (CVSS 7.8) CWE-22 / CWE-426 / CWE-209 GitHub CNA PVR: ArcadeAI/arcade-mcp
Target Repository: ArcadeAI/arcade-mcp (commit 18020d3096, 2026-10-23T21:57:16Z)
Affected Component: libs/arcade-cli/arcade_cli/start_command.py (lines 281-297, 722-730), deploy_config.py (lines 30-58, 122-141), & libs/arcade-core/arcade_core/executor.py (lines 156-163)
Researcher: Serhii Shunko (@sshunko / @ccsimplyspolit, ORCID 0009-0002-4183-0361)

1. Summary

During a defensive static source audit of `https://github.com/ArcadeAI/arcade-mcp` (`main` branch, commit `18020d3096` / `0befb59d88` / `30a0b5779f`, pushed `2026-10-23T21:57:16Z`), I identified three security defects across `arcade-cli` and `arcade-core`: 1. **Path Traversal via Recursive `-r` / `--requirement` Directives in `_requirement_specs()` (`CWE-22`, `start_command.py:281-297`)**: `_requirement_specs()` follows `-r <path>` directives in `requirements.txt` via `yield from _requirement_specs(path.parent / include.group(1), seen)` without verifying that the resolved path stays within `project_dir` or rejecting symlinks. 2. **Runtime Code-Execution Environment Variables (`LD_PRELOAD`, `PYTHONPATH`, `PYTHONSTARTUP`) Not Reserved in `deploy_config.py` & Redirect Following in `mcp_handshake()` (`CWE-426` / `CWE-918`, `deploy_config.py:30-58, 131-137` & `start_command.py:722-730`)**: `_RESERVED_NAMES` and `_RESERVED_PREFIXES` block `PATH` and `HOME` but fail to block `LD_PRELOAD`, `LD_LIBRARY_PATH`, `DYLD_INSERT_LIBRARIES`, `PYTHONPATH`, `PYTHONSTARTUP`, or `PYTHONHOME` (and perform a case-sensitive check), while `mcp_handshake()` uses `follow_redirects=True` when sending `headers`. 3. **Incomplete Fix for `ValidationError` Value Leakage in `ToolExecutor._serialize_output()` (`CWE-209`, `executor.py:156-163`)**: While commit `30a0b5779f` (*'fix(core): sanitize validation tracebacks and enforce declared input rules (#960)'*) sanitized `ValidationError` in `_serialize_input()` (`from None` and stripping `str(e)`), `_serialize_output()` right below it (`lines 158-162`) still interpolates `{e!s}` into `developer_message` and chains `from e`, leaking sensitive tool output values into error messages and stacktraces.

2. Root Cause Analysis

- **`libs/arcade-cli/arcade_cli/start_command.py:281-297`**:
```python
def _requirement_specs(path: Path, seen: set[Path]) -> Iterator[str]:
    path = path.resolve()
    if path in seen or not path.is_file():
        return
    seen.add(path)
    text = re.sub(r"\\\r?\n", " ", path.read_text(encoding="utf-8-sig"))
    for line in text.splitlines():
        line = re.sub(r"(^|\s)#.*", "", line).strip()
        include = re.match(r"(?:-r|--requirement)(?:\s*=\s*|\s+)(\S+)$", line)
        if include:
            yield from _requirement_specs(path.parent / include.group(1), seen)
```

- **BEFORE PATCH**: `check_env_before('LD_PRELOAD')` and `check_env_before('PYTHONPATH')` return `True`, `_requirement_specs()` follows `../` outside `project_dir`, and `_serialize_output()` echoes `{e!s}` with `from e`.
- **AFTER PATCH**: Blocks `LD_*`, `DYLD_*`, `PYTHONPATH`, `PYTHONSTARTUP`, and `PYTHONHOME` case-insensitively, confines `_requirement_specs()` to `project_dir.resolve()`, disables redirect following in `mcp_handshake()`, and sanitizes `ValidationError` in `_serialize_output()`.

5. Security Impact

A maliciously crafted project or deploy configuration can override runtime loader variables (`LD_PRELOAD`, `PYTHONPATH`), traverse outside the project root via `requirements.txt` `-r` includes, and leak sensitive tool output values via unsanitized Pydantic `ValidationError` exceptions in `_serialize_output()`.
