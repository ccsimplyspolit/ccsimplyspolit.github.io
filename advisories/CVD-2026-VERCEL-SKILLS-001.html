CVD-2026-VERCEL-SKILLS-001: Arbitrary Host File and Directory Read/Inclusion via Unchecked Symlink Dereferencing in copyDirectory() in vercel-labs/skills

Researcher: Serhii Shunko (@ccsimplyspolit)

Repository: vercel-labs/skills

HackerOne Program: vercel (Scope ID 1040821 — https://github.com/vercel-labs/skills)

Affected Component: src/installer.ts (lines 517-569)

Weakness / Severity: CWE-59 / CWE-61 / CWE-22 · High (CVSS 8.2)

Summary

I identified an arbitrary host file/directory inclusion vulnerability via unchecked symbolic link dereferencing in `vercel-labs/skills` (`src/installer.ts`, lines 517-569). When a user installs a skill from a Git repository (`npx skills add <repo>`), `installSkillForAgent()` invokes `copyDirectory(skill.path, canonicalDir, agentType)`. `copyDirectory()` calls `cp(srcPath, destPath, { dereference: true, recursive: true })` (and `readFile(srcPath, 'utf-8')` when `agentType === 'eve'`) without verifying that symbolic links inside the cloned repository resolve within the skill's root directory.

Impact

Installing a third-party skill repository via `npx skills add` allows a malicious skill author to copy arbitrary files or directories from the developer's machine (such as `~/.ssh/id_rsa`, `~/.aws/credentials`, `.env`, or `/etc/passwd`) into the project's `.agents/skills/<skill>/` directory, where AI coding agents automatically load the file contents into LLM context or developers commit them to version control.
