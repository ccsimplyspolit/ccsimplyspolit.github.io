CVD-2026-FALCON-MCP-001: URL Route Truncation via Unfiltered '?' and '#' Characters and Trailing-Whitespace Dot-Segment Bypass in _validate_repository() (falcon_mcp/modules/ngsiem.py)

Target Repository: CrowdStrike/falcon-mcp (commit 608986fa620e, 2026-10-22T19:34:50Z)
Affected Component: falcon_mcp/modules/ngsiem.py (lines 57-96)

1. Summary

During a defensive static source audit of `https://github.com/CrowdStrike/falcon-mcp` (`main` branch, commit `608986fa620e`, pushed `2026-10-22T19:34:50Z`), I identified an incomplete URL path-parameter validation defect in `falcon_mcp/modules/ngsiem.py` (introduced in commit `608986fa620e`): 1. **URL Query/Fragment Route Truncation (`CWE-20` / `CWE-22`, `falcon_mcp/modules/ngsiem.py:57-96`)**: `_validate_repository()` blocks `("/", "\\", "%")` (`_UNSAFE_REPOSITORY_CHARS`) and `(".", "..")` (`_DOT_SEGMENTS`) before interpolating `repository` into `/humio/api/v1/repositories/{repository}/queryjobs`. However, it does not reject `?` or `#` (nor enforce a strict identifier character set). Passing `repository="search-all? arbitrary=1#"` causes `requests` to parse `?arbitrary=1` as the query string and `#/queryjobs` as a client-side URL fragment, stripping `/queryjobs` from the outbound HTTP request path and retargeting the authenticated Falcon API call to `/humio/api/v1/repositories/search-all`. 2. **Unstripped Whitespace Bypass on `_DOT_SEGMENTS` (`CWE-20`, `falcon_mcp/modules/ngsiem.py:81-88`)**: Line 81 checks `if not repository.strip():`, but line 88 checks `repository in _DOT_SEGMENTS` against the unstripped `repository` string, allowing `".. "` or `" .."` to bypass the `_DOT_SEGMENTS` equality check.

2. Root Cause Analysis

- **`falcon_mcp/modules/ngsiem.py:57-96`**:
```python
_UNSAFE_REPOSITORY_CHARS = ("/", "\\", "%")
_DOT_SEGMENTS = (".", "..")

def _validate_repository(repository: Any) -> dict[str, Any] | None:
    if not isinstance(repository, str):
        return None

    if not repository.strip():
        return _format_error_response(
            "Invalid repository: must be a non-empty repository or view name, "
            "for example 'search-all'.",
            operation="StartSearchV1",
        )

    if any(char in repository for char in _UNSAFE_REPOSITORY_CHARS) or repository in _DOT_SEGMENTS:
        return _format_error_response(...)

    return None
```

5. Security Impact

An LLM agent or caller invoking `falcon_start_ngsiem_search` under prompt injection can inject `?` and `#` into `repository` to truncate the `/queryjobs` suffix and retarget authenticated CrowdStrike Falcon API requests to `/humio/api/v1/repositories/<repo>` with arbitrary query parameters.
