0x01 // Technical Specification & Remediation Patch

### Summary & Root-Cause Static Analysis

1. **`PAYLOAD_TYPE_TRACE` Unchecked `payload_len` Underflow (`src/Mesh.cpp:42-66`, `CWE-191` / `CWE-125`):**
   `Mesh::onRecvPacket()` reads 9 bytes (`trace_tag`, `auth_code`, `flags`) from `pkt->payload` without checking `pkt->payload_len >= 9`, causing `uint8_t len = pkt->payload_len - i` to underflow modulo 256 to `247..255` and read past the 184-byte `Packet::payload` buffer. Additionally, when `offset < len`, `self_id.isHashMatch(&pkt->payload[i + offset], 1 << path_sz)` does not verify `offset + (1 << path_sz) <= len`.

2. **`PAYLOAD_TYPE_PATH` Unchecked Decrypted Frame Length (`src/Mesh.cpp:160-179`, `CWE-191` / `CWE-125`):**
   `Packet::isValidPathLen(path_len)` verifies only `hash_count * hash_size <= MAX_PATH_SIZE (64)` without verifying `k + hash_size * hash_count + 1 <= len` (the actual decrypted payload length), causing `uint8_t extra_len = len - k` to underflow on short ciphertexts.

3. **`Packet::readFrom()` Pre-Copy Bounds Check & `Dispatcher::tryParsePacket()` Header Length Check (`src/Packet.cpp:65-85`, `src/Dispatcher.cpp:147-166`, `CWE-125`):**
   `memcpy(path, &src[i], bl)` executes prior to checking `(uint16_t)i + bl <= len`, and `transport_codes` are read prior to checking `len >= 6`.
