CVD-2026-CF-MCP-UNIFIED-001: Cross-Principal Unsubscribe Bypass, Unscoped accountId Access, Cursor Parameter Injection in EventService (src/events/service.ts) & Internal TLD Bypass in ans-bridge.ts

Target Repository: cloudflare/mcp (commit 550e1be82b, 2026-10-22T15:50:50Z)
Affected Component: src/events/service.ts (lines 132-164, 331-352) & src/events/ans-bridge.ts (lines 8-26)
Researcher: Serhii Shunko (@sshunko / @ccsimplyspolit, ORCID 0009-0002-4183-0361)

1. Summary

During a defensive static source audit of `https://github.com/cloudflare/mcp` (`main` branch, commit `550e1be82b`, pushed `2026-10-22T15:50:50Z`), I identified four security defects in the newly added Events (`cw_events` / ANS bridge) subsystem: 1. **Principal Ownership Check Bypassed When `policyId` Is Absent in `EventService.unsubscribe()` (`CWE-639`, `src/events/service.ts:132-164`)**: `unsubscribe(accountId, subscriptionId, policyId?)` only checks `state.principal !== this.principal` inside `if (policyId) { ... }`. When a caller invokes `unsubscribe(accountId, subscriptionId)` without `policyId` (or when `getState(subscriptionId)` returns `null`), `unsubscribe()` skips ownership verification and directly deletes the Cloudflare Event Subscription (`DELETE /accounts/${accountId}/event_subscriptions/subscriptions/${subscriptionId}`) and associated webhook. 2. **Missing Account Scope Check for `user_token` in `EventService.api()` (`CWE-639`, `src/events/service.ts:340-352`)**: `api(accountId)` only checks `if (this.props.type === 'account_token' && this.props.accountId !== accountId)` and fails to verify `this.props.accounts` when `this.props.type === 'user_token'`. 3. **Unvalidated `cursor` Query String Interpolation in `EventService.list()` (`CWE-20` / `CWE-88`, `src/events/service.ts:331-338`)**: `list(cursor)` computes `const page = cursor ? Number(cursor) : 1`, checks only `if (page > MAX_PAGES)`, and interpolates raw `${cursor}` into `/accounts?page=${cursor}&per_page=20`. When `cursor` is `'1&direction=asc'` (`Number(cursor)` is `NaN`, so `NaN > MAX_PAGES` is `false`), arbitrary query parameters are injected into the Cloudflare API path. 4. **Incomplete Internal Hostname Filtering in `CallbackUrl` (`CWE-918`, `src/events/ans-bridge.ts:8-26`)**: `CallbackUrl` only blocks `localhost` and `.local`, allowing RFC 6762 / RFC 8375 internal domains such as `.arpa` (`1.168.192.in-addr.arpa`), `.intranet`, `.internal`, `.corp`, `.lan`, and `.home`.

3. Steps to Reproduce (BEFORE PATCH vs. AFTER PATCH)

Run the standalone verification test suite in `verify_batch8_fresh_ai_cna.py` (`test_04_cloudflare_mcp_events_validation`):
```bash
uv run verify_batch8_fresh_ai_cna.py
```
- **BEFORE PATCH**: `unsubscribe_before('user:attacker', 'user:victim', None)` returns `'DELETED'` because `policyId` is omitted; `list_cursor_before('1&direction=asc')` injects `&direction=asc` into `/accounts?page=1&direction=asc&per_page=20`.
- **AFTER PATCH**: Enforces `state.principal === this.principal` unconditionally on `unsubscribe()`, verifies `Number.isInteger(page) && page >= 1`, validates `accountId` format and `user_token` account membership, and blocks `.arpa`, `.intranet`, `.internal`, `.corp`, `.lan`, and `.home` in `CallbackUrl`.

5. Security Impact

Any authenticated principal can delete event subscriptions and webhooks belonging to another principal simply by omitting `policyId`, inject arbitrary query parameters into `/accounts` pagination requests via `cursor`, and register internal `.arpa`/`.corp`/`.lan` webhook callback URLs.
