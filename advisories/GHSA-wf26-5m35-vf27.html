0x01 // Technical Specification & Remediation Patch

### Summary & Root-Cause Static Analysis

1. **Heap-Based Buffer Overflow & Integer Overflow in `LIEF::ELF::Segment::set_content_value<T>()` (`src/ELF/Segment.cpp:236-261`, `CWE-787` / `CWE-190`):**
   When `datahandler_ != nullptr`, `Segment::set_content_value<T>(size_t offset, T value)` checks `if (offset + sizeof(T) > binary_content.size())` — omitting `node.offset()` from the bounds comparison — before executing `memcpy(binary_content.data() + node.offset() + offset, &value, sizeof(T))` with `node.offset()` added.

2. **Heap-Based Out-of-Bounds Read in `LIEF::ELF::Segment::get_content_value<T>()` (`src/ELF/Segment.cpp:205-224`, `CWE-125`):**
   `Segment::get_content_value<T>(size_t offset)` copies `sizeof(T)` bytes from `content_c_.data() + offset` or `binary_content.data() + node.offset() + offset` without validating `offset + sizeof(T)` against `content_c_.size()`, `node.size()`, or `binary_content.size()`.

3. **Unbounded Recursion in `LIEF::DEX::Type::parse()` (`src/DEX/Type.cpp:187-195`, `CWE-674`):**
   `Type::parse(std::string_view)` recursively invokes `array_->emplace_back(type.substr(1))` on consecutive `'['` characters without enforcing the Dalvik DEX format limit of 255 array dimensions.

4. **Heap-Based Out-of-Bounds Read/Write via Desynchronized `method.code_offset_` & `method.bytecode_` (`src/DEX/Parser.tcc:695-711`, `CWE-125` / `CWE-787`):**
   `DEX::Parser::parse_code_info()` updates `method.code_offset_ = offset + sizeof(details::code_item)` even when `stream_->peek_array()` returns `nullptr`, desynchronizing `method.code_offset_` from a previously populated `method.bytecode_` buffer accessed during `VDEX::Parser::parse_quickening_info()` and `DEX::File::raw()`.
