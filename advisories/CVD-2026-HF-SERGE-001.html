CVD-2026-HF-SERGE-001: Arbitrary Executable Invocation Outside .ai/ via Unresolved Path & Symlink Traversal in run_context_script() and Persistent --user Package Upgrade in reviewbot/tools.py

High (CVSS 8.6) CWE-22 / CWE-59 / CWE-829 GitHub CNA PVR + HackerOne: huggingface
Target Repository: huggingface/serge (commit 91665cc22cbe, 2026-10-25T19:51:30Z)
Affected Component: reviewbot/context_script.py (lines 159-172) & reviewbot/tools.py (lines 122-135)
Researcher: Serhii Shunko (@sshunko / @ccsimplyspolit, ORCID 0009-0002-4183-0361)

1. Summary

During a defensive static source audit of `https://github.com/huggingface/serge` (`main` branch, commit `91665cc22cbe`, pushed `2026-10-25T19:51:30Z`), I identified two security defects in the automated PR review bot (`reviewbot`): 1. **Missing `.ai/` Containment & Symlink Canonicalization in `run_context_script()` (`CWE-22` / `CWE-59`, `reviewbot/context_script.py:159-172`)**: Whereas `reviewbot/tools.py` (`lines 991-996`) resolves helper commands via `_resolve_path()` and enforces `if path != ai_root and not path.startswith(ai_root + os.sep): raise _ToolError(...)`, `run_context_script()` computes `full = script_path if os.path.isabs(script_path) else os.path.join(base, script_path)` without `os.path.realpath()` or verifying that `full` resides under `<cwd>/.ai/`. Consequently, an absolute `script_path`, a `..` traversal sequence, or a symbolic link inside `.ai/context.sh` executes arbitrary binaries outside `.ai/` (including PR-modified scripts in the worktree or host executables). 2. **Unpinned `--upgrade` / `-U` Flag Permitted in `_INSTALL_ALLOWED_FLAGS` (`CWE-829`, `reviewbot/tools.py:122-125`)**: `_INSTALL_ALLOWED_FLAGS = frozenset({"install", "--upgrade", "-U", "--user"})` permits `--upgrade` / `-U` with `--user`, allowing a helper install step to overwrite existing packages in the persistent `~/.local/lib/python.../site-packages` environment shared across review runs.

2. Root Cause Analysis

- **`reviewbot/context_script.py:159-172`**:
```python
    if not cwd:
        return None
    base = cwd
    full = (
        script_path if os.path.isabs(script_path) else os.path.join(base, script_path)
    )
    if not os.path.isfile(full):
        log.debug("context script %s not found, skipping", full)
        return None
    if not os.access(full, os.X_OK):
        log.warning("context script %s exists but is not executable; skipping", full)
        return None
```
- **`reviewbot/tools.py:122-125`**:
```python
_INSTALL_ARG_RE = re.compile(r"^[A-Za-z0-9._\-+=,\[\]]+$")
_INSTALL_ALLOWED_FLAGS = frozenset({"install", "--upgrade", "-U", "--user"})
```
