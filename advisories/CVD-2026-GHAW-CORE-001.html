CVD-2026-GHAW-CORE-001: Predictable Non-Exclusive .tmp File Write & Permissive Mode Retention in writeCompileProgressFile (pkg/cli/compile_pipeline.go)

Target Repository: github/gh-aw (commit 6f802cae59, 2026-10-25T23:47:20Z)
Affected Component: pkg/cli/compile_pipeline.go (lines 555-566)
Researcher: Serhii Shunko (@sshunko / @ccsimplyspolit, ORCID 0009-0002-4183-0361)

1. Summary

During a defensive static source audit of `https://github.com/github/gh-aw` (`main` branch, commit `6f802cae59` / `9f68f4923f`, pushed `2026-10-25T23:47:20Z`), I identified an incomplete fix in `writeCompileProgressFile()` (`pkg/cli/compile_pipeline.go:555-566`). Commit `9f68f4923f` (*'Fix compile progress file permissions policy regression (#71947)'*) replaced `0o600` with `constants.FilePermSensitive` in `os.WriteFile(temporaryPath, []byte(output), constants.FilePermSensitive)` where `temporaryPath := progressPath + ".tmp"`. Because Go's `os.WriteFile` calls `os.OpenFile(name, O_WRONLY|O_CREAT|O_TRUNC, perm)` without `O_EXCL`, `O_NOFOLLOW`, or an explicit `Chmod`, the `perm` argument (`constants.FilePermSensitive`) is ignored by the kernel whenever `temporaryPath` already exists. A pre-existing `progressPath + ".tmp"` file with permissive mode (e.g., `0o644`) retains its world-readable permissions across `os.WriteFile` and `os.Rename(temporaryPath, progressPath)`, and a pre-existing symlink at `temporaryPath` is followed during `os.WriteFile`.

2. Root Cause Analysis

- **`pkg/cli/compile_pipeline.go:555-566`**:
```go
func writeCompileProgressFile(progressPath string, output string) error {
	if err := os.MkdirAll(filepath.Dir(progressPath), 0o750); err != nil {
		return fmt.Errorf("creating progress directory: %w", err)
	}

	temporaryPath := progressPath + ".tmp"
	if err := os.WriteFile(temporaryPath, []byte(output), constants.FilePermSensitive); err != nil {
		return fmt.Errorf("writing progress temp file: %w", err)
	}
	if err := os.Rename(temporaryPath, progressPath); err != nil {
		return fmt.Errorf("renaming progress temp file: %w", err)
	}
	return nil
}
```

- **BEFORE PATCH**: When `progressPath + ".tmp"` already exists with mode `0o644`, `os.WriteFile(..., 0o600)` truncates and writes without changing the mode, and `os.Rename` publishes `progressPath` with mode `0o644` instead of `0o600`.
- **AFTER PATCH**: Uses `os.CreateTemp(filepath.Dir(progressPath), filepath.Base(progressPath)+".*.tmp")` (which opens exclusively with `O_CREAT|O_EXCL`) and calls `tempFile.Chmod(constants.FilePermSensitive)` before `os.Rename`.

5. Security Impact

Sensitive workflow compilation progress data intended to be restricted to `constants.FilePermSensitive` (`0o600`) remains world-readable (`0o644`) if the predictable `.tmp` file pre-exists, or overwrites arbitrary files via a pre-staged `.tmp` symlink.
