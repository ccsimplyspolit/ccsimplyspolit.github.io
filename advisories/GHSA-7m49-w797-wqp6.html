0x01 // Technical Specification & Remediation Patch

### Summary & Root-Cause Static Analysis

1. **Stack-Based Buffer Overflow in `pkl__header_find_type()` (`src/modules/pickle.c:477-486`, `CWE-121`):**
   `pkl__header_find_type()` copies `mod_name.size` bytes from the pickle header into a fixed stack buffer `char buf[PK_MAX_MODULE_PATH_LEN + 1]` via `memcpy(buf, mod_name.data, mod_name.size)` without checking `mod_name.size <= PK_MAX_MODULE_PATH_LEN`.

2. **Arbitrary Relative Heap Read/Write in `PKL_MEMO_GET` & `PKL_MEMO_SET` (`src/modules/pickle.c:548-564`, `CWE-787` / `CWE-125`):**
   `p_memo[index]` is indexed directly by `int index = pkl__read_int(&p)` without verifying `0 <= index < memo_length` (or validating `memo_length >= 0` and VM stack depth above `p0`).

3. **Untrusted Pointer Dereference in `PKL_TVALUE` (`src/modules/pickle.c:733-738`, `CWE-822`):**
   `case PKL_TVALUE:` copies 16 raw bytes into a VM stack `py_TValue` slot via `memcpy(tmp, p, sizeof(py_TValue))` without rejecting `tmp->is_ptr != 0`, allowing injection of arbitrary 64-bit `PyObject*` pointers into the VM and garbage collector.
