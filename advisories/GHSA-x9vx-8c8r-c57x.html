GHSA-x9vx-8c8r-c57x: Cross-Request Session & Bearer Token Race on Shared McpServer & KChatClient (Infomaniak/mcp-server-kchat)

[PATCHED UPSTREAM IN v1.1.1 • PR #70 MERGED (COMMIT 5ed2728f5a)]
Privately reported to Infomaniak/mcp-server-kchat via GitHub Private Vulnerability Reporting (GHSA-x9vx-8c8r-c57x) covering shared mutable McpServer transport rebinding and kchatClient.setToken(token) state in src/http.ts.
Confirmed and patched upstream by Infomaniak maintainer @L3o-pold in Pull Request #70 (commit 5ed2728f5a, released in v1.1.1) using AsyncLocalStorage per-request token isolation and per-request McpServer instantiation.
