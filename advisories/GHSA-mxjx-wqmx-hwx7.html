0x01 // Technical Specification & Remediation Patch

### Summary & Root-Cause Static Analysis

1. **Incomplete Fix for `GHSA-vc5v-6vwm-wf9m` (`ZDI-CAN-29369`) in `nanobot/security/network.py` (`lines 56-75`, `CWE-918` / `CWE-184`):**
   `_normalize_addr()` only unwraps `addr.ipv4_mapped` (`::ffff:0:0/96`) and `_is_private()` checks only a static 11-entry `_BLOCKED_NETWORKS` list. IPv6 transition addresses embedding internal IPv4 targets — including NAT64 (`64:ff9b::/96` and `64:ff9b:1::/48`), 6to4 (`2002::/16`), Teredo (`2001::/32`), IPv4-compatible (`::/96`), and SIIT (`::ffff:0:0:0/96`) — as well as non-global ranges covered by `ipaddress` stdlib predicates return `False` from `_is_private()`. Additionally, `WebSearchTool._search_searxng()` in `nanobot/agent/tools/web.py:720-726` creates `httpx.AsyncClient` without `validate_url_target()` or `PinnedDNSAsyncTransport`.

2. **Command Guard Bypass & Quote-Split Path Traversal in `nanobot/agent/tools/shell.py` (`lines 426-434, 858-928, 1027-1115`, `CWE-22`):**
   In `ExecTool._prepare_command()`, `self._guard_command()` is gated behind `if access.restrict_to_workspace:`, completely skipping `deny_patterns`, `allow_patterns`, and `contains_internal_url()` in the default configuration (`restrict_to_workspace=False`). When `restrict_to_workspace=True`, `"../" in cmd` is checked only on the raw command string before `shlex.shlex(command, posix=True)` strips quotes in `_extract_absolute_paths()`, while `_extract_posix_paths_from_token()` only inspects tokens starting with `/` or `~`.
